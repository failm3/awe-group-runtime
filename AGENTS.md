> Документ для всех следующих сессий в этом репозитории. Это не автоматическая смена полномочий, не новая версия `/goal` и не свидетельство исполненного кода. Операционная директива владельца: https://github.com/failm3/nivict-ai-academy/blob/main/03%20-%20%D0%9F%D1%80%D0%B0%D0%BA%D1%82%D0%B8%D0%BA%D0%B0/05%20-%20AWE%20GROUP/

## Приоритет работы

1. Перед разработкой: искать уже реализованное в проекте, OpenCode/Hermes, 4504-каталоге, установленных MCP/API/CLI и открытом исходном коде. Не создавать новый механизм без короткого отчёта о пригодности альтернатив.
2. Предоставлять **реально исполняемые инструменты**, не только каталоги и метаданные: find → verify → sandbox/connect → smoke test → scoped adapter → delegated use → independent QA → repeatable Skill.
3. Работать на результат CAREER-01. Нужны профессиональные русскоязычные дизайны с реальными кейсами, browser screenshots/mobile QA; проверенные вакансии и правдивые CV. Не считать прототип готовым продуктом.
4. Не дублировать существующие scheduler, budget ledger, model router, registry или runtime. Сравнивать Hermes/OpenCode как исполнителей; AWE остаётся владельцем миссии и состоянием, а не бесконечной самописной заменой всего стека.
5. Различать создано, запущено, протестировано и принято. Требуются проверяемые файлы/diff/logs/screenshots/checkpoint и независимый QA; `session_move` и отчёт LLM не доказательство.
6. Сохранять original `/goal`, утверждённые 8 направлений CAREER-01, запреты внешних действий, лимиты и состояние `UNKNOWN/HOLD`. Запрещено обходить HOLD новой попыткой, личным токеном или альтернативным ключом.
7. Никаких секретов/персональных документов в этом публичном GitHub репозитории. Локальные WSL worktree могут содержать более свежие изменения; не считать `main` последним рабочим состоянием.

## Порог сдачи P0

Один реальный подключённый и прошедший smoke-test инструмент + сохранённый Skill + измеримый результат в CAREER-01 + независимая визуальная/функциональная QA с доказательствами. Работы по инфраструктуре без такой связки не считать решением запроса владельца.
